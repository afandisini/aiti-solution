Docs / Getting Started
Instalasi
  1. Pastikan file CSS tersedia di src/aiti/css/aiti.css.
  2. Import di HTML: 
    <link rel="stylesheet" href="/src/aiti/css/aiti.css">
  3. Opsional: gunakan utilitas dasar: 
    <div class="aiti-container">...</div>
Theming

Ubah variabel di :root (lihat aiti.css):

:root{
  --aiti-primary:#0d6efd;
  --aiti-radius:12px;
}

Mode gelap mengikuti prefers-color-scheme: dark.

Aksesibilitas
  • Pastikan kontras warna tombol memadai.
  • Gunakan <button> untuk aksi dan <a> untuk tautan.
  • Tambahkan fokus ring sesuai kebutuhan proyek.
